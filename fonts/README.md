# Bundled display font

`afe-frontier-display.woff2` is derived from ByteDance's DouyinSans Bold
(`DouyinSansBold.ttf`, version 1.01) and is used only for large Simplified
Chinese headings.

- Upstream: <https://github.com/bytedance/fonts/tree/main/DouyinSans>
- License: SIL Open Font License 1.1; see `OFL-LDB-Frontier-Display.txt`
- Modification: the upstream TTF was converted to WOFF2 and its reserved font
  names were replaced with `LDB Frontier Display` as required by the OFL.
