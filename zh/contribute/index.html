为 Agent Frontier Exam 提交科研任务

本轮主要征集 L1 限定目标的科研挑战。每题围绕一个已有方法尚未达成的科学目标，并提前说明哪些证据足以验证这项突破。

进入书生·端砚 ReX 科学共研计划，点击“提交科学问题”。每个任务上传一个 ZIP。

从自己的研究中选一个开放问题，整理成一份 Harbor 任务包，写清如何验证研究目标是否达成，再通过端砚提交。

端砚表单怎么填

  1. 01

    说明科研问题

    填写团队、科学问题、已有基础、Agent 输入、预期产物、资源与成功标准。合作来源选“学术合作”，等级默认 L1，也可按题目选 L2 或“暂不确定”。

  2. 02

    上传任务包

    将 task_package/ 和必要的“补充材料/”放在 ZIP 根目录。材料尚不完整时，可选“部分材料待补充”或“需协助构建任务”，注明缺失项与需要的协助。

  3. 03

    确认授权并提交

    分别确认任务使用、训练或能力改进、公开发布的授权范围，提交后保留副本。后续补充或修订时，请向对接团队注明任务名和版本关系。

AFE Research

如何准备科研任务

选题与验收

01

说明研究缺口

给出相关研究和核对日期，说明已有方法的局限，以及达成目标能带来的新贡献。

02

写清研究判断

说明 Agent 需要完成的推断、设计、实验分析或证明。

03

限定研究范围

列出输入、工具、资源、最终产物和允许探索的空间。

04

预先定义成功条件

明确支持结论所需的证据和对照。若否定结果也可达标，需预先写明覆盖范围、质控和充分性条件。

task_package/

  1. task.toml

    声明运行配置与 AFE 元信息。

  2. instruction.md

    Agent 实际读取的科研题文、交付要求和验收标准。

  3. environment/

    构建解题环境，提供 Agent 可以访问的数据和工具。

  4. tests/

    构建独立评分环境，用提交产物验证科研目标。

  5. solution/

    可选参考方法，每个方法单独一个子目录。
